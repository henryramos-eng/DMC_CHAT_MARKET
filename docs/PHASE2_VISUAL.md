# Fase 2: cinco boletines por commodity

La salida está limitada a cinco imágenes verticales y mantiene este orden:

1. Soya (QBS)
2. Harina de soya (QSM)
3. Aceite de soya (QBO)
4. Petróleo WTI (CL)
5. Diésel / ULSD (HO)

Cada imagen incluye encabezado, precio de cierre, variación porcentual y
absoluta, evolución de precios, MA20, EMA50, RSI o MACD, análisis técnico y
tres factores técnicos verificables.

El renderer elimina los PNG de ejecuciones anteriores dentro de la carpeta de
la fecha antes de producir el nuevo conjunto. De este modo el manifiesto, el
directorio y el álbum de Telegram contienen exactamente cinco imágenes.

Los mockups se conservan solamente como referencias de diseño. Sus precios,
fechas, textos y señales no se utilizan como datos de mercado.
